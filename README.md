# AMOS Web OS V14 PRO

Website portfolio dan desktop-like operating system berbasis browser yang dibuat untuk menampilkan berbagai project, dashboard, aplikasi internal, music player, terminal, file manager, dan AI chat di satu tampilan.

Repository ini dipublikasikan melalui GitHub Pages dan dirancang seperti sistem desktop modern dengan tampilan futuristic.

## Demo

- GitHub Pages: https://amosmarbun86-droid.github.io
- Repository: https://github.com/amosmarbun86-droid/amosmarbun86-droid.github.io

## Fitur Utama

- Desktop interface mirip OS
- Login dengan PIN
- Wallpaper rotator otomatis
- Matrix background effect
- Sidebar project dashboard
- AI chat window
- Browser window
- Music player
- File manager
- Terminal simulasi
- Progressive Web App (PWA)
- GitHub Pages deployment support

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- Firebase Firestore
- Cloudinary
- PWA manifest
- GitHub Pages
